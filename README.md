Entry for the [make.fun](https://make.fun/r/a46mdp44) competition
[Sum up 21 November's world news in one image](https://make.fun/bounty/news-image-20261121).

One newspaper front page (1024×1024 PNG, under 1 MiB) summing up Saturday
21 November 2026: 39 stories across 9 regions, each verified against the
day's reporting — Iran strikes Bahrain bases, a deep 6.7 quake shakes Peru,
COP31 runs into overtime, BepiColombo enters Mercury orbit, and 35 more,
with a UTC timeline, a pin map, and a date check that names what was left
out and why.

`main.ts` (Node 22, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. It is deterministic: two runs write the
same bytes.
